# Retail Sales Analysis Using Python

## Overview

This project analyzes 10,500+ retail sales transactions to identify trends, profitability drivers, regional performance, and customer behavior.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Key Insights

* West region generated the highest sales and profit.
* Central region recorded the lowest performance.
* Discounts showed a negative impact on profitability.
* Customer and product analysis identified major revenue contributors.
